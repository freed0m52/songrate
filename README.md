# Music Rating App

Веб-приложение для оценки песен с сохранением в localStorage и экспортом/импортом JSON.

## Запуск
Просто открой `index.html` в браузере (Chrome/Edge/Firefox).
Никакой сборки не нужно.

## Возможности
- ➕ Добавление песен с оценкой по слайдерам
- 💾 Сохранение в JSON (кнопка появляется при изменениях)
- 📂 Загрузка из JSON (перезаписывает список)
- 👥 Друзья с их треками
- 💞 Мэтчи: идеальные, одинаковые песни, совпадения по артистам
- ⚙️ 6 цветовых тем
- 🥇 Золотая рамка при рейтинге 40/40
- 👑 Эмодзи короны для "лучшего трека" (один на артиста)

## Рейтинг
- Музыка (0–10) + Текст (0–10) + Вайб (0–20) = **40**
- При "нет текста": (Музыка + Вайб) × 4/3 = **40**
- Вокал и Ритм дают небольшой бонус (до +2), обрезается до 40
